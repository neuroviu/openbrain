# Contributing to OpenBrain

Thank you for helping make neuroscience more accessible!

1. Open an issue describing your proposal, bug, or accessibility improvement.
2. Fork the repository and create a focused branch.
3. Keep the app dependency-free where practical; preserve keyboard accessibility and clear simulated-data labels.
4. Do not submit private health data, human biosignal recordings, or third-party code without compatible licensing and attribution.
5. Submit a pull request explaining the change and how you tested it.

By contributing, you agree that your contributions are submitted under this repository's Apache-2.0 license. NeuroViu trademarks and logos are not included in that grant.
