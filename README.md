# 🧠 NeuroViu OpenBrain™

**See More of You. Explore the Brain.**

OpenBrain is a **free, browser-based, open-source educational tool** for exploring *simulated* EEG, ViuGaze™ (EOG), and EMG waveforms. No headset, electrodes, signup, or server required.

## Website

Once GitHub Pages is enabled for this repository, visit **https://neuroviu.github.io/openbrain/**.

## Run locally

Open `index.html` in a modern browser. No dependencies, build process, or data uploads.

## Features

- Select synthetic EEG, ViuGaze™, or EMG waveform examples.
- Adjust signal intensity and see the chart update.
- Download synthetic CSV data for learning and experimentation.
- Read brief explanations of each modality.

## Safety and limitations

These are illustrative mathematical signals, **not recordings from people or validated physiological models**. This is an educational demonstration, not a medical device, diagnostic tool, or clinical decision system. The intensity slider and CSV values are in arbitrary units, not calibrated microvolts.
